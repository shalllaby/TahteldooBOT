# 🌐 منظومة موقع الويب المستقلة — جريدة تحت الضوء الإخبارية v4.0

هذا المجلد **مستقل تماماً بنسبة 100%**، ويحتوي على كافة ملفات ومكونات موقع الويب والسيرفر المركزي للجريدة دون أي اعتمادية على ملفات خارجية.

---

## 📁 محتويات المجلد بالتفصيل:

| المجلد / الملف | الوصف |
| :--- | :--- |
| **`web/`** | الواجهة الأمامية للموقع (HTML, CSS, JavaScript, الصور والأيقونات). |
| **`web_server.py`** | السيرفر المركزي ومحرك الـ API (FastAPI) الذي يدير كافة الطلبات. |
| **`core/`** | إعدادات المنظومة ونظام السجلات المتقدم. |
| **`database/`** | طبقة الاتصال بقاعدة البيانات وإدارة العمليات. |
| **`services/`** | خدمات الذكاء الاصطناعي (Z.AI)، النشر في بلوجر، الواتساب، والصور. |
| **`telegram_bot/`** | موديول التحكم ببوت التليجرام والمزامنة. |
| **`storage/`** | مجلد التخزين المحلي للصور، وسجلات الأحداث، وقاعدة البيانات `app.db`. |
| **`assets/`** | الشعار والأصوات والملفات الثابتة. |
| **`.env`** | إعدادات البيئة ومفاتيح الربط ومعرّف المدونة (`3967122067465937059`). |
| **`credentials.json`** | بيانات مشروع Google Cloud OAuth. |
| **`token*.pickle`** | جلسات حسابات Google Blogger المعتمدة للنشر. |
| **`requirements.txt`** | حزم بايثون المطلوبة للتشغيل. |
| **`deploy_vps.sh`** | سكربت التثبيت والتشغيل التلقائي على سيرفر Contabo VPS. |
| **`update.sh`** | سكربت التحديث السريع بضغطة زر من GitHub. |
| **`run_server.bat`** | زر تشغيل فوري على ويندوز. |
| **`run_server.sh`** | زر تشغيل فوري على لينكس. |
| **`theme_tahteldoo_fixed.xml`** | قالب بلوجر المعدل بالكامل والجاهز للرفع. |

## 🚀 طريقة التشغيل:

### أولاً: التشغيل على جهازك الشخصي (ويندوز)
اضغط مرتين على ملف **`run_server.bat`**، ثم افتح المتصفح على:
`http://localhost:8000`

### ثانياً: التشغيل على سيرفر VPS (Contabo / Linux)
1. انقل هذا المجلد إلى السيرفر: `/root/tahteldoo_web_platform`.
2. شغّل السكربت الآلي:
   ```bash
   cd /root/tahteldoo_web_platform
   chmod +x deploy_vps.sh update.sh run_server.sh
   ./deploy_vps.sh
   ```
3. الموقع سيعمل 24/7 على: `http://SERVER_IP:8000`.
